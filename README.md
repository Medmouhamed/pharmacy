#  Pharmacy Management System 

A robust, full-stack management solution designed to streamline pharmacy operations, inventory tracking, and prescription management. This project demonstrates advanced skills in database schema design, backend logic, and responsive frontend integration.

## 🏗️ System Architecture
The project follows a **3-Tier Architecture** model to ensure scalability and separation of concerns:
1. **Presentation Tier**: Responsive web interface for pharmacists and admins.
2. **Logic Tier (Middleware)**: Robust backend handling business rules, role-based access control (RBAC), and JWT authentication.
3. **Data Tier**: High-performance data management using **Oracle Database** .

## 🚀 Key Features
* **Inventory & Drug Catalog**: Automated tracking of stock levels with SQL triggers for expiration and low-stock alerts.
* **Smart Prescription Search**: Search functionality by Patient Name or ID for quick retrieval.
* **Role-Based Access (RBAC)**: Secure administrative dashboard for managing staff and permissions.
* **Secure Authentication**: Integrated **JWT (JSON Web Tokens)** for secure API communication.
* **Data Persistence**: Efficient database operations including schema exports and log management.
