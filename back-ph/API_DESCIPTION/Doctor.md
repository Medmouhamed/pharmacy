# Project: Doctor

## End-point: GET DOCTORS
| الخاصية | التفاصيل |
| --- | --- |
| **اسم المسار** | استعراض قائمة الأطباء بالكامل |
| **الطريقة (Method)** | `GET` |
| **الرابط (URL)** | `http://localhost:3000/doctors` |
| **الوصف المنطقي** | تنفيذ استعلام جلب كافة بيانات الأطباء وتخصصاتهم من جدول `DOCTOR`. |
| **الرد الناجح** | `200 OK` مع مصفوفة JSON تحتوي على جميع سجلات الأطباء. |
### Method: GET
>```
>http://localhost:3000/doctors
>```

## End-point: GET DOCTOR BY ID
| الخاصية | التفاصيل |
| --- | --- |
| **اسم المسار** | البحث عن طبيب بواسطة المعرف |
| **الطريقة (Method)** | `GET` |
| **الرابط (URL)** | `http://localhost:3000/doctors/:id_doctor` |
| **الوصف المنطقي** | البحث عن طبيب معين باستخدام معرفه الرقمي الفريد `ID_D` الممرر في الرابط. |
| **الرد الناجح** | `200 OK` مع بيانات الطبيب، أو `404` في حال عدم وجوده. |
### Method: GET
>```
>http://localhost:3000/doctors/1
>```

## End-point: POST DOCTOR
| الخاصية | التفاصيل |
| --- | --- |
| **اسم المسار** | تسجيل طبيب جديد في النظام |
| **الطريقة (Method)** | `POST` |
| **الرابط (URL)** | `http://localhost:3000/doctors/add` |
| **الوصف المنطقي** | إدخال سجل جديد يحتوي على (الاسم، التخصص، العنوان) مع تفعيل الحفظ التلقائي `autoCommit`. |
| **الرد الناجح** | `200 OK` مع رسالة تأكيد نجاح العملية 🟢. |
### Method: POST
>```
>http://localhost:3000/doctors/add
>```
### Body (**raw**)

```json
{
    "NAME_D": "John Smith",
    "SPECIALITY": "General Medicine",
    "ADDRESS": "New York - Manhattan"
}
```

## End-point: DELETE DOCTORS
| الخاصية | التفاصيل |
| --- | --- |
| **اسم المسار** | حذف طبيب من قاعدة البيانات |
| **الطريقة (Method)** | `DELETE` |
| **الرابط (URL)** | `http://localhost:3000/doctors/delete/:id_doctor` |
| **الوصف المنطقي** | حذف الطبيب مع التحقق برمجياً من وجود سجلات طبية مرتبطة به لمنع حذف الأطباء النشطين. |
| **الرد الناجح** | `200 OK` في حال الحذف، أو `409` إذا وُجدت سجلات تمنع الحذف. |
### Method: DELETE
>```
>http://localhost:3000/doctors/delete/1
>```

## End-point: UPDATE DOCTOR
| الخاصية | التفاصيل |
| --- | --- |
| **اسم المسار** | تعديل بيانات طبيب موجود |
| **الطريقة (Method)** | `PUT` |
| **الرابط (URL)** | `http://localhost:3000/doctors/update/:id_doctor` |
| **الوصف المنطقي** | تحديث حقول (الاسم، التخصص، العنوان) والتحقق عبر `rowsAffected` من وجود السجل قبل التحديث. |
| **الرد الناجح** | `200 OK` مع رسالة تأكيد التعديل أو `404` في حال عدم وجود الطبيب. |
### Method: PUT
>```
>http://localhost:3000/doctors/update/1
>```
### Body (**raw**)

```json
 {
        "NAME_D": "John Smith",
        "SPECIALITY": "General Medicine",
        "ADDRESS": "Geulma - Manhattan"
    }
```
