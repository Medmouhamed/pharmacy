# Project: Patient

## End-point: GET PATIENTS
| الخاصية | التفاصيل |
| --- | --- |
| **اسم المسار** | استعراض كافة المرضى المسجلين |
| **الطريقة (Method)** | `GET` |
| **الرابط (URL)** | `http://localhost:3000/patientes` |
| **الوصف المنطقي** | تنفيذ استعلام لجلب كافة سجلات المرضى من جدول `PATIENT` بصيغة كائنات JSON. |
| **الرد الناجح** | `200 OK` مع قائمة تحتوي على كافة بيانات المرضى. |
### Method: GET
>```
>http://localhost:3000/patientes
>```

## End-point: GET PATIENT BY ID
| الخاصية | التفاصيل |
| --- | --- |
| **اسم المسار** | البحث عن مريض محدد (Patient Profile) |
| **الطريقة (Method)** | `GET` |
| **الرابط (URL)** | `http://localhost:3000/patientes/:id_patient` |
| **الوصف المنطقي** | جلب بيانات مريض واحد باستخدام معرفه الرقمي الفريد `ID_P` الممرر في الرابط. |
| **الرد الناجح** | `200 OK` مع بيانات المريض، أو `404` في حال عدم وجوده. |
### Method: GET
>```
>http://localhost:3000/patientes/1
>```

## End-point: POST PATIENTS
| الخاصية | التفاصيل |
| --- | --- |
| **اسم المسار** | تسجيل مريض جديد في النظام |
| **الطريقة (Method)** | `POST` |
| **الرابط (URL)** | `http://localhost:3000/patientes/add` |
| **المدخلات (Body)** | `FANAME` (الاسم)، `LNAME` (اللقب)، `AGE` (العمر). |
| **الرد الناجح** | `200 OK` مع رسالة تأكيد النجاح 🟢. |
### Method: POST
>```
>http://localhost:3000/patientes/add
>```
### Body (**raw**)

```json
{
    "FANAME": "Ahmed",
    "LNAME": "Mansouri",
    "AGE": 45
}
```

## End-point: DELETE PATIENT
| الخاصية | التفاصيل |
| --- | --- |
| **اسم المسار** | حذف سجل مريض من المنظومة |
| **الطريقة (Method)** | `DELETE` |
| **الرابط (URL)** | `http://localhost:3000/patientes/delete/:id_patient` |
| **حماية البيانات** | يمنع الحذف (`409 Conflict`) إذا كان للمريض وصفات سابقة لضمان سلامة الأرشيف. |
### Method: DELETE
>```
>http://localhost:3000/patientes/delete/2
>```

## End-point: PATIENT HISTORY
| الخاصية | التفاصيل |
| --- | --- |
| **اسم المسار** | تقرير التاريخ الطبي للمريض (Medical History) |
| **الطريقة (Method)** | `GET` |
| **الرابط (URL)** | `http://localhost:3000/patientes/history/:id_patient` |
| **الوصف المنطقي** | تجميع بيانات الوصفات والأدوية والأطباء المباشرين وجهات الصرف في كائن واحد منظم. |
| **المميزات** | يستخدم نظام التجميع (Reduce) لربط عدة أدوية تحت وصفة واحدة لتسهيل العرض. |
### Method: GET
>```
>http://localhost:3000/patientes/history/2
>```

>```
