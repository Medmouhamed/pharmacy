# Project: Pharmacy Project

## End-point: GET SHELFS by CATEGORY
| الخاصية | التفاصيل |
| --- | --- |
| **اسم المسار** | جلب أرفف فئة محددة (Category Specific Shelfs) |
| **الطريقة (Method)** | `GET` |
| **الرابط (URL)** | `http://localhost:3000/shelfs/:categoryId` |
| **المعاملات (Params)** | `categoryId`: رقم الفئة الطبية المراد معرفة أرففها. |
| **الوصف المنطقي** | تصفية الأرفف بناءً على الفئة لتسهيل عملية ترتيب وتخزين الأدوية. |
| **الرد الناجح** | `200 OK` مع قائمة بمعرفات الأرفف (IDS) المرتبطة بالفئة. |
### Method: GET
>```
>http://localhost:3000/shelfs/1
>```

## End-point: GET CATEGORYIES
| الخاصية | التفاصيل |
| --- | --- |
| **اسم المسار** | عرض الفئات الطبية (Medical Categories) |
| **الطريقة (Method)** | `GET` |
| **الرابط (URL)** | `http://localhost:3000/categories` |
| **الوصف المنطقي** | استرجاع كافة التصنيفات الطبية (مثل: مسكنات، مضادات) من جدول `CATEGORY`. |
| **الرد الناجح** | `200 OK` مع قائمة بأسماء ومعرفات الفئات. |
### Method: GET
>```
>http://localhost:3000/categories
>```
